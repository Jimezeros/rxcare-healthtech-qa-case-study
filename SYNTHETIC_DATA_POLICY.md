# Synthetic Test Data Policy

Only fictional data may be stored in this repository.

## Permitted examples

- identifiers using the prefix `SYN-`;
- fictional medication records created solely for test design;
- synthetic roles, timestamps, audit events, and consent metadata;
- clearly labelled AI-output examples used as evaluation artifacts.

## Prohibited content

- real patient, prescription, pharmacy, or customer data;
- employer, client, or production-system records;
- copied proprietary interfaces or workflows;
- personal email addresses, phone numbers, account identifiers, or private URLs;
- credentials, tokens, keys, or configuration secrets.

All datasets must be reviewed before publication.
